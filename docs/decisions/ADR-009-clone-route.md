# ADR-009：克隆技术路线（zero-shot vs fine-tune）

- 状态：**兜底规则已锁定，spike 待跑（阶段 0 第二周）**
- 依据：docs/architecture.md 2.5（克隆语义）/ 6 · 阶段 0（兜底规则原文）/ §11 索引

## 兜底规则（6/阶段 0 v1.3 写入，不再讨论）

> 结论满足「fine-tune 质量 ≥ zero-shot + 可感知阈值，或优势场景有产品价值」
> 且「训练时长 ≤ 5 分钟（目标硬件）」才采用 fine-tune；**48 小时无结论 →
> 默认 zero-shot 上线，fine-tune 转入阶段 2 优化项**。

## 第二周 spike 清单（预登记）

1. CosyVoice2 zero-shot：3–6 秒样本 → 音色嵌入 → 合成听感（与源样本近似度人工盲听）。
2. fine-tune（LoRA 若引擎支持）：同样本 → 训练时长实测（目标硬件 T-8G）→ 同听感口径。
3. 产出各项填表：质量 / 训练时长 / 资产量级 → 按兜底规则判定，结果写入本文档。
