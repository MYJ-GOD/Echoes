# Echoes 前端重设计 · 设计规范与实施计划

> 版本：v0.1 · 2026-11-02
> 范围：主窗口、设置窗口、首启向导、HUD 的视觉与交互规范
> 不涉及：IPC 协议、sidecar、Rust 业务命令、数据库结构、模型与引擎实现
> 唯一例外：窗口几何（`tauri.conf.json` 与 `open_settings_window` 的尺寸），因为布局规范依赖它
> 上游依据：[开发计划.md](开发计划.md) §6.1（窗口与页面）、§0.2（七条核心体验）、§0.3（三条铁律）
> 现状证据：`tmp/ui-review/index.html`（1100×760 四张真实截图）

## 0. 决策摘要

先看这一页。后面所有细节都服从这里。

| # | 决策 | 结论 |
|---|---|---|
| 1 | 技术栈 | **保持 Tauri 2 + Vue 3**。不迁移 Electron，不引入组件库，不引入 Pinia |
| 2 | 产品骨架 | **五页 + 左侧窄导航 + 设置独立窗口**，按开发计划 §6.1 收口 |
| 3 | 主题 | **一套布局，两套 token**（Light / Dark）；删除所有用主题改布局的规则 |
| 4 | 默认外观 | **跟随系统**；Light 是身份，Dark 是同等的另一套，不是"夜间补丁" |
| 5 | 默认窗口 | 主窗 1100×760（最小 800×600）；设置窗 720×760（最小 640×700）。当前是 800×600 / 560×820，需改 `tauri.conf.json` 与 `open_settings_window` |
| 6 | 视觉方向 | **纸上回声 / Paper & Signal**：冷纸、墨、深绿信号、珊瑚只用于录音 |
| 7 | 签名元素 | **回声线**：会随"听 / 想 / 说"变化的一条声纹，不是装饰 |
| 8 | 字体 | UI 用系统无衬线；她的正文用衬线；元信息用等宽。首版不打包字体，先量回退 |
| 9 | 设置模型 | 一个 schema 驱动分组、搜索、重置、变更记录；显式保存，显示"未保存" |
| 10 | 实施顺序 | **先拆组件与壳，再改视觉**；每一步都能 `npm run build` |
| 11 | 工期 | 约 6 个工作日（单人、含截图回归） |
| 12 | 验收 | 3 个尺寸 × 2 套主题的截图 + 对比度 + 键盘路径 + 构建通过 |

**一句话**：不是把现在的页面刷一层新颜色，而是先把"网页感"换成"桌面应用感"，再让视觉为声音和记忆服务。

## 1. 现状诊断

### 1.1 实测数据

| 指标 | 现状 | 问题 |
|---|---|---|
| 主内容宽度 | `.app { max-width: 680px }` | 1100px 窗口里左右各空 210px，像一篇居中的文章 |
| 页眉品牌 | 标题栏 `ECHOES` + 页眉 `ECHOES` + 名字 `Echoes` | 同一信息出现三次，占掉首屏 70px |
| 主操作可见性 | `.ptt:disabled { opacity: .45 }` | 引擎连接中时，首屏最重要的按钮几乎看不见 |
| 主题实现 | `themes.css` 600 行，用 `[data-theme]` 改布局 | 夜灯 `column-reverse` 翻转输入区，台面隐藏 wordmark；三套产品 |
| 设置 | 400px 抽屉，8 个板块 | 外观/人设/LLM/ASR/TTS/模型/设备/音色/数据/诊断一条长滚动 |
| 主题选择器 | 3 列网格放 4 项 | 第 4 项掉到第二行，孤行 |
| 错误呈现 | `TypeError: Cannot read properties of undefined` 直接显示 | 原始异常当文案，没有恢复动作 |
| 代码体量 | `Chat.vue` 4097 行（模板 1218 / CSS 1545） | 任何视觉改动都在 4k 行里做，回归半径极大 |
| 页面外壳 | 对话页/记忆页/标题栏各写一套页头 | 没有共享 `AppShell`，层级和间距不一致 |
| 视觉验收 | PROGRESS 记录"未做像素级验收" | 没有截图基线，改坏了看不出来 |

### 1.2 根因

1. **骨架和规划脱节**：计划 §6.1 是"左导航 + 五页 + 独立设置"，代码是"单页 + 历史抽屉 + 记忆页 + 设置抽屉"。
2. **主题承担了布局职责**：主题切换的不只是颜色，还有结构；三套都得不到打磨。
3. **缺少设计系统**：只有颜色和字体 token，没有间距、字号、圆角、层高、动效、状态规范。
4. **缺少桌面应用常识**：没有命令与快捷键体系、没有独立设置窗口、没有空/错/加载态的统一样式、没有键盘路径。
5. **视觉方向踩中 AI 默认脸**：暖米色 `#F6F1E8` + 高对比衬线 + 陶土色 `#95512F`，正好是 `frontend-design` skill 点名的第一种模板感配色。

### 1.3 不做什么

- 不为了"好看"换 Electron。Tauri 的 WebView2 和 Electron 的 Chromium 渲染能力几乎一样；换栈只会让安装包从 24.7MB 变成 200MB+。
- 不引入 Element Plus / Naive UI / shadcn-vue。现有依赖只有 Vue + Router，保持零新增运行时依赖。
- 不做移动端、虚拟人、动态壁纸、复杂粒子。
- 不重做 IPC 和业务逻辑；所有改动在渲染层。

## 2. 设计目标

### 2.1 三个目标

1. **像一个桌面应用，不像一个网页**：有窗口、有导航、有菜单/快捷键、有设置窗口、有密集列表和稳定布局。
2. **声音是第一入口，但不是唯一入口**：按住说话始终是主操作；打字同等可用，不因为语音优先而把输入区做小。
3. **记忆可见、可控、可追溯**：记忆不是藏在设置里的功能，而是和对话并列的一等页面。

### 2.2 体验原则

| 原则 | 落到界面 |
|---|---|
| 安静，但不空 | 留白服务于阅读，不是为了显得高级；每个空态都给一个可执行的下一步 |
| 在场感 | 状态灯、回声线、正在说/正在想的状态必须一眼可见，不靠猜 |
| 一致性 | 同一动作只有一个名字、一种位置、一个样式；按钮、字段、列表、对话框全部来自同一套 primitive |
| 键盘优先 | 所有点击目标都有键路径；快捷键可改；焦点始终可见 |
| 可恢复 | 错误说人话，给两条出路；绝不把异常原文当文案 |
| 不装饰 | 任何动效都必须解释状态变化；`prefers-reduced-motion` 下全部归零 |

## 3. 视觉方向：纸上回声 / Paper & Signal

### 3.1 概念

Echoes 是"记得你们聊过一切"的声音伴侣。视觉不从"AI 产品"里找，而从**纸、声纹、夜间书房**里找：

- **纸**：记忆与信件的隐喻，但用**冷纸**，不用暖奶油色。
- **墨**：正文的高对比，不靠浅灰"高级感"。
- **信号**：一条深绿（verdigris）作为系统色，像旧仪器上的刻度。
- **珊瑚**：只给"正在录音 / 停止"这一种状态，别的地方不出现。
- **声纹**：一条会呼吸的线，承担"她在听/她在想/她在说"的状态表达。

这不是"换一个主题"，而是把原来的"信笺 + 陶土 + 衬线"从 AI 默认脸里拉出来，保留"纸"的隐喻，换掉它的套路。

### 3.2 签名元素：回声线

一条 1.5px 的线，出现在三个地方，含义一致：

| 位置 | 形态 | 含义 |
|---|---|---|
| 空态中央 | 静止的三段弧线 | 她在等 |
| 输入区上方 | 横向波形，随麦克风电平起伏 | 她在听 |
| 她的消息左侧 | 一条短竖线 + 两个刻度 | 这句话是"她说"的 |

规则：

- 只在 `listening` / `generating` / `speaking` 时动；`ready` 时静止。
- 只改变高度/透明度/位移，不用 `width`/`height` 触发重排。
- 动效时长 900–1400ms，`prefers-reduced-motion` 下固定为静态波形。
- 不做彩色渐变、不做粒子、不做 3D。

#### 硬性对比度

- 正文与背景 ≥ **4.5:1**；大字号（≥18.66px bold 或 ≥24px）≥ **3:1**。
- 图标与控件边框 ≥ **3:1**。
- 禁用态文字仍要 ≥ **3:1**，不能靠 `opacity: .45` 消失。
- 主题选择器、状态灯、错误条、输入框边框都要在明暗两套下各测一次。

### 3.4 字体

```css
--font-ui:
  "Segoe UI Variable Text", "Segoe UI", system-ui, -apple-system,
  "Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", sans-serif;
--font-voice:
  "Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia, serif;
--font-mono:
  "Cascadia Mono", Consolas, ui-monospace, "SF Mono", monospace;
```

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 24 / 32 | 500 | 空态主句、关于页标题 |
| Title | 18 / 26 | 600 | 页面标题 |
| Body | 14 / 22 | 400 | 界面正文、表单、列表 |
| Voice | 16 / 27 | 400 | 她的回复正文（衬线） |
| Meta | 12 / 16 | 500 | 时间、状态、标签 |
| Mono | 12 / 16 | 400 | 引擎名、耗时、快捷键 |

规则：

- **最小 12px**，不再出现 9.5/10/11px 的"精致小字"。
- 中文衬线在 Windows 上可能掉到 SimSun，首版先接受并用截图确认；如果观感不达标，第二阶段打包 `Noto Serif SC` 子集（SIL OFL，约 3–5MB WOFF2），不引 Google Fonts。
- 数字与时间统一用等宽，避免列表跳动。

### 3.5 间距、圆角、层高、动效

**间距**：4px 网格。常用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。

| token | 值 |
|---|---|
| `--space-1` | 4px |
| `--space-2` | 8px |
| `--space-3` | 12px |
| `--space-4` | 16px |
| `--space-5` | 20px |
| `--space-6` | 24px |
| `--space-8` | 32px |
| `--space-10` | 40px |
| `--space-12` | 48px |

**控件高度**：小 24 / 标准 32 / 大 40。图标按钮 32×32。导航项 36 高。

**圆角**：控件 4 / 卡片 8 / 浮层 12 / 胶囊 999。不再出现 9/10/14/16 混用。

**层高**：

| token | 值 | 用途 |
|---|---|---|
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.04)` | 卡片 |
| `--shadow-2` | `0 8px 24px rgba(0,0,0,.10)` | 弹层 / 菜单 |
| `--shadow-3` | `0 24px 64px rgba(0,0,0,.22)` | 对话框 |

**动效**：

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover / 颜色 | 100ms | `cubic-bezier(.2,0,0,1)` |
| 进入 / 展开 | 160ms | `cubic-bezier(.2,0,0,1)` |
| 退出 / 收起 | 90ms | `cubic-bezier(.4,0,1,1)` |

- 只动 `color / background-color / border-color / opacity / transform`。
- `prefers-reduced-motion: reduce` 时全部 0ms，回声线固定为静态图。

### 3.6 密度

- `data-density="comfortable"`（默认）：行高 36，页面内边距 24。
- `data-density="compact"`：行高 30，页面内边距 16，正文行高 20。
- 密度是**设置项**，不是第三套主题；只改间距 token，不改布局结构。

## 4. 信息架构

### 4.1 主窗口

```
┌ 标题栏 36 ──────────────────────────────────────────────────────┐
│ Echoes                                            ─   □   ×    │
├───────────┬─────────────────────────────────────────────────────┤
│ 对话      │  声音与人格            ● 就绪    内置音色    ⋯     │
│ 历史      │─────────────────────────────────────────────────────│
│ 记忆      │                                                     │
│ 声音      │                 页面内容                            │
│ 关于      │                                                     │
│           │                                                     │
│           │─────────────────────────────────────────────────────│
│ ⚙ 设置    │  输入区 / 按住说话                                  │
└───────────┴─────────────────────────────────────────────────────┘
```

- 侧栏宽度：展开 208px，收起 64px；窗口 ≥980px 默认展开，<980px 自动收起。
- 侧栏只放导航，不放品牌大标题；品牌只在标题栏出现一次。
- 底部固定"设置"，点击打开**独立窗口**；创建失败时回退到主窗口 `/settings` 整页，不使用抽屉。
- 当前路由项：左侧 2px 主色条 + `--accent-soft` 底；hover 只改背景，不改位置。
- 国际惯例：`Ctrl+,` 打开设置；`Ctrl+Shift+P` 命令面板；`Ctrl+F` 当前页搜索；`Ctrl+Shift+F` 全局搜索。

### 4.2 五个页面

| # | 路由 | 页面 | 职责 | 空态 |
|---|---|---|---|---|
| 1 | `/` | 对话 | 消息流 + PTT + 状态 | 「她还在听。」+ 3 个开场建议 |
| 2 | `/history` | 历史 | 会话列表 + 搜索 + 只读回看 | 「对话会自动保存在本机。」 |
| 3 | `/memory` | 记忆 | 事实卡片 + 来源 + 编辑/删除/添加 | 「聊得越多，这里越丰富。」 |

| 5 | `/about` | 关于 | 版本、更新、诊断、许可 | —— |
| — | `/settings` | 设置回退 | 独立窗口失败时的整页回退 | —— |

- 窗口 720×760，最小 640×700；左侧导航 176px，右侧内容自适应。

- 每行设置：`label` + 可选 `help` + 控件 + 默认值提示 + 单项重置。

- 不把"彻底删除"和常规设置放同一视觉层级；危险区永远独立、带二次确认。

## 5. 页面规范

### 5.1 对话页

#### 页眉

- 左：她的名字（18/26，600）+ 状态（`● 就绪 / 正在想 / 正在说 / 启动中 / 出错`）。
- 右：当前音色 chip、三链状态 chip（隐私模式 / 联网模式）、更多菜单。
- 不再出现 `ECHOES` 眉标；不再把"历史"放在页眉（历史是导航项）。
- 高度 48px，底部 1px `--rule`。

#### 消息流

```
09:41  她  │ 我还记得你说过，雨天喜欢听爵士。
           │ 今天也下雨了。
           │
09:42  你  │ 放一首吧。
```

- 两列：时间/角色 gutter 64px（等宽 12px，`--ink-3`）+ 正文。
- 她的消息：左侧 2px `--accent` 竖线 + 衬线 16/27；不画头像。
- 用户消息：`--surface-2` 底、4px 圆角、无边框；sans 14/22。
- 消息间距 24px；同角色连续消息间距 12px。
- 流式光标：2px 竖线，1s 闪烁；`prefers-reduced-motion` 时静止。
- 被打断：正文后一行 12px「已打断」，不做删除线。
- 错误：独立 `notice` 行，`--danger` 左边框 + 一句人话 + 最多两个动作；不伪装成她的消息。
- 自动跟读：距底 >64px 时停止抢滚动；出现「回到最新」胶囊。

#### 空态

- 垂直位置：消息区上方 1/3，不是正中悬浮。
- 主句 24/32：「她还在听。」
- 副句 14/22：「按住空格说话，或者写一句。」
- 3 个建议 chip（可点击填入输入框，不直接发送）：「今天有点累」「讲个故事」「你还记得……」
- 不使用大插画；回声线做背景签名。

#### 输入区

```
┌──────────────────────────────────────────────────────────────┐
│  ⌾ 按住说话    │ 写点什么…                          [➤]    │
└──────────────────────────────────────────────────────────────┘
  按住空格说话 · 松开发送                    ● 已连接 · 本地
```

- 一个完整表面：`--raised` 底、1px `--rule-strong`、8px 圆角、内边距 6px。
- 左侧 PTT 按钮 40×40：麦克风图标；按住说话，松开结束；busy 时变成"打断"（`--signal`）。
- 中间 textarea：1–5 行自适应，14/22，无边框；`Enter` 发送，`Shift+Enter` 换行。
- 右侧发送按钮 32×32：有内容时主色，空时禁用但仍可见。
- 输入区上方 12px 回声线，只在 listening 时起伏。
- 下方一行 12px 提示：状态 + 当前链路；不再同时放"按住说话"和"语音引擎就绪后可用"两套话。
- 禁用态：PTT 保持可见，`--ink-3` 边框 + tooltip「引擎启动中」；不要整体 `opacity: .45`。

#### 状态

| 状态 | 页眉 | 输入区 | 主操作 |
|---|---|---|---|
| connecting / booting | `● 启动中` | 可输入，发送禁用 | PTT 禁用 + tooltip |
| ready | `● 就绪` | 正常 | 按住说话 |
| generating | `● 正在想` | 保留输入 | PTT = 打断 |
| speaking | `● 正在说` | 保留输入 | PTT = 打断 |
| error | `● 出错` | 错误条 + 重试/设置 | 重试 |
| read-only | `● 只读` | 禁用 + 修复入口 | 设置 |

#### 文案

- 启动中：「正在准备声音…」
- 就绪：「她在听。」
- 生成中：「正在想…」
- 说话中：「正在说…」
- 通用错误：「这次没接上。可以重试，或去设置看看引擎。」
- 只读：「引擎连续失败，暂时只能查看历史与记忆。」

### 5.2 历史页

- 两栏：列表 320px + 只读预览；窗口 <900px 时列表全宽，预览覆盖进入。
- 顶部：搜索框（`Ctrl+F` 聚焦）、新建对话、显示已归档。
- 分组：今天 / 本周 / 更早；每条显示标题、最后活跃时间、消息数、归档标记。
- hover 显示：改名、归档、删除；删除是两步确认。
- 预览：原文一字不差，标记"只读"；顶部「继续对话」是唯一进入编辑态的入口。
- 空态：「对话会自动保存在本机。」+「开始第一段对话」。
- 搜索命中：高亮片段 + 轮次号；没有命中时给"清除搜索"。

### 5.3 记忆页

- 顶部工具条：搜索、分类 chips（全部/偏好/身份/事件/其他）、添加、批量导入、合并。
- 卡片网格：宽 ≥1000px 两列，否则一列；卡片 8px 圆角、1px `--rule`、12px 内边距。
- 卡片内容：事实正文 14/22 → 分类 + 来源 + 最近使用（12px）→ 操作（编辑/来源/删除）。
- 「看过它的回复」展开为内联 disclosure，不跳页；来源行可点回历史轮次。
- 合并模式：顶部出现选择条「已选 N 条」+ 合并；选择框只在合并模式出现。
- 危险操作：删除用 `--danger` 文字按钮 + 确认对话框；不放在主操作区。
- 空态：「聊得越多，这里越丰富。」+「手动添加一条」。

### 5.4 声音页

- 当前音色卡片：名称、来源（内置/克隆/云端）、质量分、试听、设为当前。
- 音色列表：行高 56，显示名称、状态（ready/training/failed）、质量、操作。
- 克隆入口：一个主按钮「克隆我的音色（3–6 秒）」；录音时显示倒计时 + 波形 + 取消。
- 配额：`已用 N / 20`，接近上限时提示；删除前必须切回内置音色。
- 未就绪/失败：置灰 + 原因 tooltip；不静默替换。
- 空态：「先用内置音色，或克隆一个。」

### 5.5 关于页

- 版本（读运行中的 build）、更新检查、诊断包导出、日志目录、开源许可、隐私说明。
- 不放大段营销文案；每项一行说明 + 一个动作。

### 5.6 首启向导

- 复用同一套 token 和 primitive；三屏：检测 → 准备 → 选 LLM。
- 每屏一个主操作；可"稍后再说"；退出不丢已完成步骤。
- 下载进度用 determinate progress；超过 1s 才显示；可取消。
- 逐链同意用 checkbox + 明确的"数据会发往哪里"；未同意时该链路不可用，不静默降级。

### 5.7 HUD

- 复用 Dark token；不写死颜色。
- 一行状态 + 波形 + 取消；最近一句回复一行，点击展开主窗口。
- 不抢焦点、不占任务栏；`prefers-reduced-motion` 时波形静止。

## 6. 组件清单

所有页面只允许使用下列组件；缺组件先补组件，不在页面里写一次性样式。

### 6.1 基础

| 组件 | 变体 / 状态 | 说明 |
|---|---|---|
| `Button` | primary / secondary / ghost / danger；sm 24 / md 32 / lg 40；loading / disabled | 一个布局只能有一个 primary |
| `IconButton` | 32×32；tooltip | 必须有 `aria-label` + tooltip |
| `Field` | label / help / error / required | label 永远在控件上方，placeholder 只做例子 |
| `TextInput` | 32 高；invalid / disabled / readonly | 错误用 `aria-describedby` |
| `TextArea` | 1–5 行自适应 | Enter 发送、Shift+Enter 换行由 Composer 决定 |
| `Select` | 32 高 | 原生 `<select>` 优先 |
| `Checkbox` / `Switch` / `RadioGroup` | — | 立即生效用 Switch；表单保存用 Checkbox |
| `SegmentedControl` | 2–4 项 | 主题/密度 |
| `Chip` | 可选 / 可关闭 | 分类、建议、状态 |
| `StatusDot` | ready / active / waiting / error | 永远带文字，不只靠颜色 |
| `Card` | 8px 圆角、1px 边框 | 不嵌套卡片 |
| `ListRow` | 36 / 30 高；hover / selected | 左文右操作，状态不放到 700px 外 |
| `Dialog` | 确认 / 危险 / 表单 | 焦点进入第一个非破坏性控件；Esc 取消 |
| `Toast` | 成功 / 失败 / 信息 | 4s 自动消失；错误不只用 toast |
| `EmptyState` | 标题 + 一句 + 一个动作 | 不用大插画 |
| `ErrorState` | 人话 + 两条出路 | 不显示异常原文 |
| `Skeleton` | 行 / 卡片 | 500ms 内不显示，避免闪烁 |
| `Tooltip` | 250ms 延迟 | 焦点也触发；`title` 不算 tooltip |
| `Meter` | 电平 / 进度 / 配额 | 只动 transform/opacity |

## 7. 交互规范

### 7.1 键盘

| 快捷键 | 动作 | 作用域 |
|---|---|---|
| `Ctrl+,` | 打开设置窗口 | 全局 |
| `Ctrl+Shift+P` | 命令面板 | 全局（P1） |
| `Ctrl+F` | 当前页搜索 | 历史 / 记忆 |
| `Ctrl+Shift+F` | 全局搜索 | 全局（P1） |
| `Alt+Space` | 全局按住说话 | 可配置 |
| `Space` | 按住说话（焦点在 PTT 上） | 对话页 |
| `Enter` | 发送 | 输入框 |
| `Shift+Enter` | 换行 | 输入框 |
| `Esc` | 关闭当前浮层 / 取消编辑 | 全局 |
| `Tab` / `Shift+Tab` | 焦点前后移动 | 全局 |
| `↑` / `↓` | 列表/命令面板移动 | 列表 |

规则：

- 所有点击目标都有键路径；`Ctrl+Shift+P` 的命令面板从同一张命令表生成，不能有第二套。
- 快捷键可改；冲突时明确报错，不静默覆盖。
- 输入框内 `Space` 永远输入空格，不触发 PTT。
- 焦点环 2px `--focus`，offset 2px；不用 `outline: none`。

### 7.2 焦点与可访问性

- 对话框打开：焦点进入第一个非破坏性控件；关闭后回到触发按钮。
- 侧栏、列表、命令面板：roving tabindex；组内一个 tab stop。
- 状态变化用 `aria-live="polite"`；错误用 `role="alert"`。
- 图标按钮必须有可读名称；图片有 `alt`；颜色不是唯一信息载体。
- 目标尺寸 ≥24×24；主要控件 32 高。
- 支持 200% 缩放不横向滚动；800×600 下无溢出。

### 7.3 状态与反馈

| 场景 | 表现 |
|---|---|
| 页面加载 | 骨架屏；>500ms 才出现 |
| 操作进行中 | 按钮 loading + 文案「保存中…」，不整页 spinner |
| 成功 | 行内状态 / toast；不弹模态 |
| 失败 | 行内错误 + 恢复动作；错误码只进日志，不进主文案 |
| 空 | 一句人话 + 一个动作 |
| 断开 | 顶部状态条 + 重连；不阻断阅读历史 |

### 7.4 文案

- 用用户的话命名，不用子系统名：说"声音"而不是"TTS 链路"，说"记得的事"而不是"memory_fact"。
- 按钮是动词：「保存设置」「开始对话」「克隆我的音色」。
- 错误说三件事：发生了什么、为什么、现在能做什么。
- 一个概念一个词：全站统一"对话 / 历史 / 记忆 / 声音 / 设置"。
- 不用感叹号、不用"智能""赋能""无缝"。

### 8.3 主题实现

```css
:root[data-theme="light"] { /* Light token */ }
:root[data-theme="dark"]  { /* Dark token */ }

@media (prefers-color-scheme: dark) {
  :root[data-theme="system"] { /* 映射到 Dark */ }
}
```

- `data-theme` 只允许在 `system | light | dark` 之间切换，不承载布局。
- 旧 `paper / nocturne / desktop` 不再作为主题；`desktop` 若保留，改为 `data-density="compact"`。
- 主题选择器用 `SegmentedControl`（跟随系统 / 浅色 / 深色），不做 4 张预览卡。
- 反色/高对比模式：先不做；确保 token 结构可扩展。

### 8.4 状态与数据

- 继续使用现有 composable，不引状态库。
- 设置仍然"写 SQLite → sidecar 下一轮拉取"；UI 只展示 `target` 与 `active`。
- 错误码到文案的映射集中在 `lib/messages.ts`；页面不再拼接 `String(err)`。
- 所有异步操作统一 `{ idle, loading, success, error }` 四态，避免每页各写一套。
